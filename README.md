# 🍕 Pizza Sales Analysis Using SQL

## 📌 Project Overview

This project analyzes pizza sales data using **SQL** to understand order patterns, revenue performance, customer preferences, and pizza category performance.

The analysis uses **Basic, Intermediate, and Advanced SQL queries** to generate meaningful business insights from pizza sales data.

## 🎯 Business Questions

### 🔹 Basic Analysis

1. Retrieve the total number of orders placed.
2. Calculate the total revenue generated from pizza sales.
3. Identify the highest-priced pizza.
4. Identify the most common pizza size ordered.
5. List the top 5 most ordered pizza types along with their quantities.

### 🔹 Intermediate Analysis

6. Find the total quantity of each pizza category ordered.
7. Determine the distribution of orders by hour of the day.
8. Find the category-wise distribution of pizzas.
9. Group orders by date and calculate the average number of pizzas ordered per day.
10. Determine the top 3 most ordered pizza types based on revenue.

### 🔹 Advanced Analysis

11. Calculate the percentage contribution of each pizza type to total revenue.
12. Analyze the cumulative revenue generated over time.
